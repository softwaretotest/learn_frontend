# TERM OF SW DEV

## Developer Terminology Dictionary

### Glossary: Technical Terms Reference

| Term / Concept                 | Thai                              | English              | Deutsch                 |
| :----------------------------- | :-------------------------------- | :------------------- | :---------------------- |
| **Transpiler / Transcompiler** | ตัวแปลงโค้ด                       | Transpiler           | Transpiler              |
| **Dedicated**                  | เฉพาะสำหรับลูกค้ารายหนึ่ง         | Dedicated            | Dediziert               |
| **B-Tree Index**               | ดัชนีโครงสร้างต้นไม้แบบสมดุล      | B-Tree Index         | B-Baum-Index            |
| **Zustand Store**              | ตัวจัดการสถานะ                    | State Management     | Zustandsverwaltung      |
| **Middleware**                 | ตัวคั่นกลาง                       | Middleware           | Middleware              |
| **Authentication**             | การยืนยันตัวตน                    | Authentication       | Authentifizierung       |
| **Authorization**              | การกำหนดสิทธิ์                    | Authorization        | Autorisierung           |
| **Validation**                 | การตรวจสอบข้อมูล                  | Validation           | Validierung             |
| **Seeder**                     | ข้อมูลตัวอย่าง                    | Seeder               | Seeder                  |
| **Factory**                    | ตัวสร้างข้อมูลทดสอบ               | Factory              | Factory                 |
| **DTO**                        | วัตถุสำหรับส่งข้อมูลระหว่างระบบ   | Data Transfer Object | DTO                     |
| **Atomic Update**              | อัปเดตแบบทำทีเดียวจบ              | Atomic Update        | Atomare Aktualisierung  |
| **Atomic Operation**           | การทำงานที่ไม่ถูกแทรกกลางคัน      | Atomic Operation     | Atomare Operation       |
| **Concurrency**                | การทำหลายงานพร้อมกัน              | Concurrency          | Nebenläufigkeit         |
| **Thread**                     | เส้นทางการทำงานในโปรแกรม          | Thread               | Thread                  |
| **Race Condition**             | การแข่งกันเขียนจนข้อมูลผิด        | Race Condition       | Race Condition          |
| **Database Locking**           | การล็อกข้อมูลใน DB กันคนอื่นแก้   | Database Locking     | Datenbanksperre         |
| **Row Lock**                   | ล็อกข้อมูลแถวเดียวใน DB           | Row Lock             | Zeilensperre            |
| **Transaction**                | ชุดคำสั่ง DB ที่ต้องสำเร็จทั้งหมด | Transaction          | Transaktion             |
| **Optimistic Lock**            | เช็คเวอร์ชันก่อนอัปเดต            | Optimistic Locking   | Optimistisches Sperren  |
| **Pessimistic Lock**           | ล็อกก่อนแก้กันชน                  | Pessimistic Locking  | Pessimistisches Sperren |
| **Stateless**                  | ไม่มีสถานะค้างระหว่าง request     | Stateless            | Zustandslos             |
| **Stateful**                   | มีสถานะค้างระหว่าง request        | Stateful             | Zustandbehaftet         |
| **Singleton**                  | 1 instance ต่อระบบ                | Singleton            | Singleton               |
