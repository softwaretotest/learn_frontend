# Naming

สรุป convention ของโปรเจกต์ Laravel ของคุณ ณ วันนี้ ผมจะเข้าใจว่า:

// Class
ProductDTO
ProductStore
ProductService
ProductRepository
ProductController

// Variable
$productDTO
$productStore
$productService
$productRepository
$productController

// Constant
RECORD
PRODUCT_TABLE

และผมจะ generate code ตาม convention นี้ให้คุณต่อไปได้อย่างสอดคล้องครับ.
